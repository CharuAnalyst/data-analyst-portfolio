Call Center Performance Dashboard (Excel)

Overview

This project presents an interactive Call Center Dashboard built using Microsoft Excel to analyze customer call data and monitor overall performance. The dashboard helps in identifying trends, evaluating agent efficiency, and improving customer satisfaction.


Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Data Cleaning & Transformation
* Charts & Data Visualization



Key Metrics

* Total Calls Handled: **1000+**
* Total Call Duration
* Average Customer Rating
* Happy Callers Count
* Revenue/Amount Generated

 📈 Dashboard Features

* Dynamic filtering using slicers
* Monthly call trend analysis
* Agent-wise performance tracking
* Gender-based caller comparison
* Call distribution by days of the week
* Customer satisfaction rating analysis


🔍 Key Insights

* Peak call volume observed during mid-week days
* Certain agents consistently handled higher workloads
* Customer satisfaction varied across regions and agents
* Call trends showed fluctuations across months
* High-rated calls contributed significantly to overall performance
