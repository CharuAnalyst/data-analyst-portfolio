📈 Sales Performance Dashboard (Power BI)

Overview

This project presents an interactive Sales Performance Dashboard developed using Power BI. It focuses on analyzing sales data to identify trends, track key performance indicators, and support data-driven decision-making.

Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization


📊 Key Metrics

* Total Sales: **21M+**
* Total Quantity Sold: **2M+**
* Revenue by Product and Region
* Time-based Sales Trends

📈 Dashboard Features

* Interactive slicers for filtering by Year, Country, and Product
* KPI cards for quick performance overview
* Time-series analysis for tracking growth trends
* Region-wise and product-wise comparisons
* Clean and user-friendly layout


🔍 Key Insights

* Sales peaked during mid-year periods
* UK and USA contributed the highest revenue
* Top-performing products generated a major share of sales
* Seasonal patterns influenced overall sales performance
