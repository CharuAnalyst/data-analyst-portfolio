🛒 Superstore Sales Dashboard (Power BI)

📌 Overview

This project presents an interactive Superstore Sales Dashboard developed using Power BI. It focuses on analyzing sales, profit, and order trends to provide meaningful business insights and support data-driven decision-making.

Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization


📊 Key Metrics

* Total Sales: **252K+**
* Total Orders: **3K+**
* Total Profit: **27K+**
* Category-wise and Region-wise Performance


📈 Dashboard Features

* Interactive filters for Category, Region, and Time
* KPI cards for Sales, Orders, and Profit
* Sales and profit comparison across segments
* Shipping mode analysis
* Trend visualization using charts
* Clean and user-friendly dashboard design

🔍 Key Insights

* Technology category generated the highest revenue
* South region showed strong performance
* Cash on Delivery (COD) was the most commonly used payment method
* Some categories showed high sales but lower profitability
